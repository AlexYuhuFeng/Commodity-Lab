# Interactive handbook milestone

Goal: extend existing Commodity Lab with business-model context and written knowledge while keeping generative interaction. Universal chapter/card contracts; European gas and crude content only.

Acceptance: bilingual hub, beach, regas, refinery and inventory chapters; inspect commercial economics/risks/mitigation; ask contextual questions; AI assembles approved cards; request fresh numerical practice and submit for verified explanation; resume conversation; open existing practice/Risk Lab; no future leakage or private-answer leakage; no regression to existing workflows; numerical reference, UI, browser, visual, build and packaging checks. AI unavailable is explicit and does not block reading or checked practice.

High risks: treating editorial draft as authority; generalizing beach/regas conventions; AI financial authority or invented citations/actions; losing chapter context; future session leakage; exposing practice solutions; replacing working workflows; silently claiming competency from one exercise.

This milestone does not build full LNG economics/FX/terminal inventory simulation, arbitrary AI executable scenarios, new commodity models, authoring CMS or enterprise identity. Beach/regas margin exercises are deliberately simplified EUR/MWh examples with declared assumptions.
