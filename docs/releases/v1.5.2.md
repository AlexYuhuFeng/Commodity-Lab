# Commodity Lab v1.5.2

## 中文

本版本重点修复 DeepSeek 密钥文件兼容与结构化训练案例生成。

### 修复

- 导入仅包含 `DEEPSEEK_API_KEY` 的配置文件时，自动识别供应方为 DeepSeek。
- DeepSeek 结构化任务启用 JSON Output，降低 `JSON decode failed`。
- 结构化响应为空时自动重试一次。
- 提高训练案例结构化输出长度上限，降低长案例被截断的概率。
- DeepSeek 固定使用程序内置的官方兼容端点与模型配置。
- API Key 继续保存在本机；Windows 使用当前用户 DPAPI 加密。

### 使用

1. 打开左下角“设置”。
2. 供应方选择 `DeepSeek`。
3. 输入 DeepSeek API Key 并保存。
4. 状态显示已就绪后生成训练案例或使用 AI 助手。

> 已知问题：API Key 保存失败时输入框会被清空。此问题由 `v1.5.3` 修复。

## English

This release focuses on DeepSeek key-file compatibility and structured training-case generation.

### Fixed

- Infer DeepSeek automatically when an imported file contains `DEEPSEEK_API_KEY` without an explicit provider.
- Enabled JSON Output for structured DeepSeek requests to reduce `JSON decode failed` errors.
- Added one automatic retry when a structured response is empty.
- Increased the structured response token allowance to reduce truncated training cases.
- Kept the DeepSeek endpoint and model route fixed inside the application.
- Continued local credential persistence, with per-user Windows DPAPI encryption.

### Setup

1. Open Settings from the lower-left menu.
2. Select `DeepSeek` as the provider.
3. Enter the DeepSeek API key and save.
4. After the provider reports ready, generate a training case or use the AI assistant.

> Known issue: a failed API-key save clears the input. This is fixed in `v1.5.3`.
