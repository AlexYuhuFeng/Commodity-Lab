# Commodity Lab v1.5.3

## 中文

本补丁修复 DeepSeek API Key 配置与发布版本一致性。

### 修复

- 保存前通过 DeepSeek 官方模型接口验证 API Key；无效密钥不会写入本机配置。
- 验证失败时保留密钥输入，用户可直接修改并重试。
- 对 DeepSeek `401` 鉴权失败显示明确的中英文提示，不再只显示通用错误。
- API Key 仍仅保存在本机；Windows 使用当前用户 DPAPI 加密。
- 将桌面端、后端、Python 包及更新检查版本统一为 `1.5.3`。
- GitHub Release 自动读取对应版本的 UTF-8 双语说明。
- 延长首次冷启动的后端等待时间，避免较慢设备被过早判定为离线。

### 安装包

- Windows x86_64：NSIS 与 MSI。
- Linux x86_64：Debian 包与 AppImage。
- Linux ARM64：Debian 包与 AppImage。

## English

This patch fixes DeepSeek API-key setup and release-version consistency.

### Fixed

- Validate an API key against DeepSeek's official models endpoint before saving it locally.
- Keep the key editable after validation fails so the user can correct and retry it.
- Show a clear bilingual message for DeepSeek `401` authentication failures.
- Continue storing the key only on the device, protected by per-user Windows DPAPI.
- Align the desktop, backend, Python package, and update-check versions on `1.5.3`.
- Make GitHub Releases load the matching UTF-8 bilingual notes file.
- Extend the first-run backend wait so slower cold starts are not marked offline prematurely.

### Packages

- Windows x86_64: NSIS and MSI.
- Linux x86_64: Debian package and AppImage.
- Linux ARM64: Debian package and AppImage.
